# Облачный запуск

`worker.mjs` — версия бота для Cloudflare Workers Free с постоянным хранилищем D1. Python-версия остаётся доступна для локального запуска.

## Сборка и проверка

```sh
python cloudflare/build.py
node --test cloudflare/worker.test.mjs
```

Для тестов нужен Node.js 24+. Каталог и вопросы берутся из `content/packages.py`, логика — из `cloudflare/worker-core.mjs`. Не редактируйте сгенерированный `worker.mjs` вручную.

## Развёртывание

1. Создайте Worker `goshapa-order-bot` на бесплатном тарифе и вставьте содержимое `worker.mjs` в редактор.
2. Создайте D1, выполните `schema.sql` и привяжите базу к Worker под именем `DB`.
3. Добавьте секреты `BOT_TOKEN`, `WEBHOOK_SECRET` (случайная строка) и переменную `ADMIN_ID`.
4. Проверьте `/health`: ожидается `{"ok":true}`.
5. Остановите локальный polling и установите Telegram webhook на `https://<worker>.workers.dev/telegram`, передав `secret_token`, `max_connections=1` и `allowed_updates=["message","callback_query"]`. Не удаляйте ожидающие обновления.

`bot.py` отказывается запускать локальный polling, пока настроен webhook. Это защищает облачную версию от случайного отключения. Для осознанного возврата к локальному запуску сначала удалите webhook через Telegram Bot API.

## Поведение и ограничения

- Анкеты и заявки переживают остановку Worker. Новые номера имеют вид `GS-C<update_id>` и не пересекаются с локальными номерами `GS-000001`.
- Повторная доставка одного обновления не создаёт новую заявку и не продвигает анкету повторно. Отправка сообщений повторяется с последнего сохранённого шага; при сетевом обрыве после фактической отправки отдельное сообщение может повториться.
- Подтверждения и уведомления разделены на несколько сообщений. Каждый ответ ограничен 500 символами, чтобы текст помещался в лимиты Telegram даже после HTML-экранирования.
- Старые карточки остаются в чате; повторное подтверждение после завершения анкеты не создаёт новый заказ.
- Фото пакетов загружаются из публичного GitHub-репозитория.
- При недоступности Telegram или блокировке бота администратором доставка может задерживаться; заявки уже находятся в D1. Администратор должен отправить боту `/start`.
- Бесплатный тариф ограничен квотами Cloudflare. Платные услуги не подключаются автоматически этой конфигурацией. Непрерывная доступность навсегда не гарантируется.

Документация: https://developers.cloudflare.com/workers/platform/pricing/ и https://developers.cloudflare.com/d1/platform/pricing/
